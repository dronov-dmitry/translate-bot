# 🤖 Telegram Voice Translator Bot

Телеграм бот для перевода голосовых и текстовых сообщений на выбранный язык с возможностью озвучивания переводов.

## 🌟 Возможности

- 📝 **Перевод текстовых сообщений** на множество языков
- 🎤 **Распознавание и перевод голосовых сообщений**
- 🔊 **Озвучивание переводов** с помощью синтеза речи
- 🌍 **Поддержка 20+ языков** включая русский, английский, испанский, французский, немецкий и другие
- ⚙️ **Гибкие настройки** вывода (только текст, только голос, или оба варианта)
- 💾 **Сохранение пользовательских настроек**
- 💎 **Система монетизации** с бесплатным лимитом и Premium подпиской
- 📊 **Статистика использования** и отслеживание активности
- 🌐 **Multi-server support** - распределение нагрузки между несколькими серверами с автоматическим failover
